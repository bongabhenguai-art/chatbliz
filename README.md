# Chatbliz OS

Chatbliz is an independent, chat-first business partner workspace. It brings My Business, My Brand, My Website & App, and My Studio into one interface, coordinated by Mentor, Coach, Assistant, Advisor, and Negotiator.

## Run locally

This is a dependency-free static app. Serve this folder with any static file server, then open `index.html`.

```sh
npm test
python3 -m http.server 4173
```

## Current scope

- Responsive, chat-first workspace shell and four product areas.
- AI Problem Solver planning flow for common business bottlenecks, with measurable next steps and a reusable skill at [`skills/business-problem-solver/SKILL.md`](skills/business-problem-solver/SKILL.md).
- Local planning and role routing only; no live model or external action is claimed.
- Account connections, persistent cloud workspace, AI providers, Studio, builder, WhatsApp, payments, and publishing still require implementation and authorization.
- Package prices are carried from the project notes and must be confirmed before checkout; billing cadence for Starter, Growth, and Studio remains unconfirmed.

Chatbliz runs separately from Bonga Bhengu OS. Shared tools can be connected through authorized interfaces later.
